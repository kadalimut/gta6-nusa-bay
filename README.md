# Nusa Bay — Open-World Crime Game

An original top-down 2D open-world crime game set in the coastal city of Nusa Bay. Raka owes a debt to the harbour crew, so he takes jobs from Dara at Cafe Dara: drive across the city, collect crates at Dermaga Timur, and escape by boat at Marina Teluk.

Explore the city on foot and by car, steal cars, dodge traffic and pedestrians, raise a wanted level and outrun the police, complete three chained missions, fight with a pistol, and watch it all on a HUD with a live minimap. The game runs offline in a desktop browser from its own static files.

Made for the make.fun bounty [Make GTA 6](https://make.fun/bounty/gta6-01).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD / arrows to move, E to steal or enter a car, mouse to aim, click / Space to shoot, P to pause, Q to save, M to mute.

Original art, names, characters and story only: no Rockstar Games logo, artwork, character or map is used.
